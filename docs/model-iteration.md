# M1–M5 模型迭代路径

## 总体思路

迭代以街景图像中的具体误差为起点：先建立像素级分割基线，再扩大场景覆盖，随后拆分建筑轮廓与建筑内部开口识别，并针对道路和地面误分加入困难负样本。最后用高分辨率预训练模型检查小窗与远距离立面的表达能力。

## M1：初始三分类 U-Net

- 目标：验证 U-Net 识别背景、墙体和开口的可行性。
- 数据：101 张标注图像。
- 结果：第 54 轮验证损失最低（0.4225），mIoU 58.83%，像素准确率 79.91%。
- 问题：样本覆盖不足，阳台、栏杆、反光玻璃和复杂遮挡下边界容易断裂。

## M2：扩充样本的三分类 U-Net

- 改动：保持结构和基础损失不变，扩充建筑高度、立面材质、开窗节奏和拍摄视角。
- 数据：248 张标注图像（论文概述为约 250 张）。
- 结果：第 45 轮验证损失最低（0.3095），mIoU 68.32%，像素准确率 84.36%。
- 结论：数据多样性是提高固定类别立面分割泛化能力的关键因素。

## M3：两阶段 U-Net

- 改动：将“建筑与背景分离”和“墙体与开口分类”拆成两个子模型。
- 第一阶段：建筑/背景二分类，最佳第 44 轮，验证损失 0.1270，mIoU 85.19%。
- 第二阶段：仅在建筑区域内识别墙体和门窗，最佳第 25 轮，验证损失 0.2936，mIoU 67.85%。
- 局限：存在级联误差；第一阶段的漏分会直接删除后续可识别的开口。

## M4：道路地面困难负样本抑制模型（最终选用）

- 改动：第一阶段改为背景、建筑、道路/地面三分类，将道路/地面交叉熵权重提高至普通类别的 8 倍。
- 第一阶段：最佳第 48 轮，验证损失 0.2397，mIoU 68.99%，像素准确率 93.32%。
- 第二阶段：最佳第 28 轮，验证损失 0.2878，mIoU 67.46%。
- 选型依据：外部样本复核中能较稳定地保持建筑轮廓、墙体连续性和窗洞阵列，对建筑底部干扰抑制更稳定。

## M5：高分辨率 ResNet18-U-Net

- 改动：将随机初始化的 U-Net 编码器替换为 ImageNet 预训练 ResNet18，输入提高至 1024×1024。
- 数据：300 张，固定划分为 240 张训练、60 张验证。
- 参数：编码器学习率 1×10⁻⁵，解码器学习率 1×10⁻⁴；类别权重约为 0.888、0.947 和 1.165。
- 结果：第 57 轮验证损失最低（0.2792），mIoU 77.25%，像素准确率 87.17%，开口 IoU 70.88%，WWR MAE 7.58 个百分点。
- 结论：整体像素分类提高，但部分外部图像存在开口扩张、墙体破碎或玻璃幕墙连续误分，因此仅作探索性对照。

## 为什么最终选择 M4

该任务的目标是稳定计算 WWR，不是单纯追求最高的内部 mIoU。M5 在像素指标上更高，但小窗边界和开口面积的小偏差会直接传递到 WWR。在同一批外部图像上综合检查建筑轮廓、墙体连续性、窗洞阵列与道路干扰后，M4 表现更稳定，因此作为当前后续 WWR 预测模型。
